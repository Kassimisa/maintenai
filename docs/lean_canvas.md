# Lean Canvas — MaintenAI

*Team Kaizen · UM6P Explorer F26 · hypothèses initiales, à valider en entretiens clients*

| Bloc | Contenu |
|---|---|
| **1. Problème** | Pannes imprévues et maintenance réactive ; diagnostic lent qui dépend de quelques techniciens seniors ; documentation technique dispersée (papier, PDF, mémoire des équipes). |
| **Alternatives existantes** | Maintenance préventive à intervalles fixes, appel au constructeur, recherche manuelle dans les manuels, GMAO classique sans IA, Excel. |
| **2. Segments de clients** | PME industrielles au Maroc avec équipements critiques et petite équipe de maintenance. Secteurs à tester : agroalimentaire ; sous-traitants mines/phosphates/chimie ; plasturgie et sous-traitance automobile. Utilisateur : technicien. Acheteur : responsable maintenance / directeur d'usine. |
| **Early adopters** | Responsables maintenance de PME ayant subi des arrêts coûteux récents, avec machines équipées de capteurs ou d'automates. |
| **3. Proposition de valeur unique** | Moins d'arrêts imprévus et des diagnostics plus rapides : MaintenAI détecte les anomalies avant la panne et guide le technicien pas à pas grâce aux manuels de l'usine. |
| **Concept** | « Un copilote IA pour les techniciens de maintenance. » |
| **4. Solution** | Détection d'anomalies sur les données capteurs ; assistant IA (RAG) sur les manuels et l'historique d'interventions ; base documentaire centralisée. |
| **5. Canaux** | Prospection directe, intégrateurs industriels et fournisseurs d'équipements, pilotes gratuits ou à prix réduit, écosystème UM6P / StartGate. |
| **6. Revenus** | Abonnement B2B par site ou par équipement + frais d'installation. Hypothèses à tester : prix acceptable, modèle préféré. |
| **7. Coûts** | Cloud et stockage, modèles IA, capteurs pour les pilotes, développement, déploiement et support. |
| **8. Indicateurs clés** | Pilotes lancés, précision des alertes / fausses alertes, temps de diagnostic, arrêts évités, usage par technicien, conversion pilote → client. |
| **9. Avantage injuste** | À construire : expertise terrain, données des pilotes, intégration simple avec l'existant, ancrage UM6P. |

## Hypothèses clés à tester

| # | Hypothèse | Test | Critère de validation |
|---|---|---|---|
| 1 | Les PME subissent des arrêts imprévus coûteux (> 1 par mois) | 15 entretiens responsables maintenance | ≥ 60 % confirment |
| 2 | Le diagnostic est ralenti par l'accès à la documentation | 10 techniciens interrogés | ≥ 30 min de recherche par panne |
| 3 | Les machines ont des capteurs ou automates exploitables | Visites d'usines | ≥ 50 % des sites |
| 4 | Le responsable maintenance décide ou influence l'achat | Question directe | ≥ 70 % des cas |
| 5 | Les clients paieraient un abonnement mensuel par site | 2–3 niveaux de prix testés | ≥ 3 lettres d'intention |
| 6 | Les techniciens utiliseraient un assistant IA sur mobile | Démo + test d'usage | ≥ 3 usages / semaine en pilote |
